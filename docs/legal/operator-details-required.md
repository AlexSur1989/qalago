# Сведения об операторе — обязательны до публикации

**Статус:** DRAFT — LEGAL REVIEW REQUIRED  
**Версия пакета:** 2026-10-03-draft-1  
**Дата:** 2026-10-03

До перевода любого публичного юридического документа QalaGo в статус «опубликован» оператор долен предоставить **точные** реквизиты и контакты. В черновиках используются плейсхолдеры ниже — **не подставлять вымышленные данные**.

## Обязательные поля

| Плейсхолдер | Описание | Где используется |
|-------------|----------|------------------|
| `[OPERATOR_LEGAL_NAME]` | Полное наименование юридического лица (или ФИО ИП, если применимо) | Все публичные и внутренние документы |
| `[BIN]` | Бизнес-идентификационный номер (БИН) | Privacy, Terms, Offer, внутренние политики |
| `[LEGAL_ADDRESS]` | Юридический адрес регистрации | Privacy, Terms, Offer |
| `[POSTAL_ADDRESS]` | Почтовый адрес (если отличается) | Privacy, запросы субъектов данных |
| `[SUPPORT_EMAIL]` | Общая поддержка пользователей и бизнеса | Terms, Community, Help, жалобы |
| `[PRIVACY_EMAIL]` | Контакт по персональным данным / DPO (если назначен) | Privacy, Consent, data-rights |
| `[PHONE]` | Контактный телефон (при наличии публичной линии) | Privacy, Offer (опционально) |
| `[WEBSITE]` | Канонический публичный URL (например `https://qalago.kz`) | Все публичные документы |
| `[REGISTRATION_DETAILS_IF_REQUIRED]` | Сведения о государственной регистрации / уведомлении уполномоченного органа по ПД (если counsel подтвердит обязанность) | Privacy, внутренние политики |

## Дополнительно для публикации (не плейсхолдеры в тексте, но обязательны операционно)

- Подтверждённый **языковой процесс** для RU и KK (редактор + казахстанский юрист).
- **Банковские реквизиты** для ручной оплаты планов/рекламы (если отображаются в продукте) — согласовать с Offer, не дублировать в Privacy без необходимости.
- **Хостинг / регион** обработки БД и медиа (для processor register и cross-border).
- **Договоры / DPA** с Google, Apple, Firebase, SMS (когда выбран), S3-провайдером (если включён).
- **Политика возвратов** — текст для Public Offer (`[REFUND_POLICY — LEGAL REVIEW REQUIRED]` до утверждения).
- **Возрастная политика / работа с несовершеннолетними** — до снятия LEGAL REVIEW в Privacy и Terms.

## Связь с env (продукт)

После утверждения counsel значения должны быть согласованы с:

- `NEXT_PUBLIC_LEGAL_OPERATOR_NAME`, `NEXT_PUBLIC_LEGAL_ADDRESS`, `NEXT_PUBLIC_PRIVACY_CONTACT_EMAIL`, `NEXT_PUBLIC_SUPPORT_CONTACT_EMAIL`, `NEXT_PUBLIC_QALAGO_PUBLIC_BASE_URL` (см. `docs/legal-review-required.md`).
