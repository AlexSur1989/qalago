## 3. Область действия

3.1. Политика описывает обработку персональных данных при использовании:

- мобильного приложения QalaGo (Flutter);
- публичного сайта QalaGo (Consumer Web);
- кабинета владельца бизнеса (Business Web);
- связанного API (`services/catalog-api`).

3.2. Политика не заменяет договорные документы для бизнеса ([Условия для бизнеса](../business/business-terms.ru.md), [Публичная оферта](../business/public-offer.ru.md), [Правила рекламы](../business/advertising-rules.ru.md)).

## 4. Термины

4.1. **Персональные данные** — сведения, относящиеся к определённому или определяемому субъекту, в значении законодательства РК о персональных данных.

4.2. **Обработка** — любые действия с персональными данными (сбор, запись, хранение, использование, передача, обезличивание, удаление и т.д.).

4.3. **Пользователь** — физическое лицо, использующее QalaGo как потребитель и/или как представитель бизнеса.

## 5. Категории данных и цели

| Категория | Примеры (факт продукта) | Цель | Обязательность |
|-----------|-------------------------|------|----------------|
| Учётная запись | идентификатор пользователя, роль (USER/BUSINESS/…), статус активности | регистрация, доступ, безопасность | обязательно для аккаунта |
| Имя / профиль | отображаемое имя | профиль, отзывы | опционально |
| Телефон | номер в формате E.164 | вход по OTP, приглашения в команду | опционально (социальный вход) |
| Email | адрес | контакт, приглашения | опционально |
| Город | preferredCityId | каталог по городу | опционально |
| Аутентификация | Google/Apple идентификаторы, метаданные провайдера | вход через Google/Apple | при выборе провайдера |
| OTP | хеш кода, телефон | подтверждение входа | временно (~5 мин) |
| Избранное | businessId | UX | опционально |
| Отзывы | оценка, текст | UGC | опционально |
| Жалобы / модерация | ContentReport, ModerationCase | безопасность, соблюдение правил | при использовании функции |
| Уведомления | тип, payload | доставка уведомлений в приложении | при событиях |
| Push | токен устройства (FCM) | push-уведомления | опционально, при включении |
| Заявки бизнеса / претензии владения | BusinessApplication, ownership claims | онбординг владельца | при подаче заявки |
| Данные бизнеса | название, адрес, координаты локаций, контакты, медиа | каталог, карта | данные владельца/бизнеса |
| Заказы и оплаты | Order, Payment, PlanPayment (суммы, статусы) | монетизация, учёт | для платных услуг бизнеса |
| Рекламная аналитика | sessionId, тип события, placement | статистика рекламы, лимиты показов | без привязки userId в AnalyticsEvent |
| Web-сессия | cookie `qalago_web_session` (32 hex) | корреляция ad/analytics на сайте | анонимная сессия браузера |
| Права субъекта | DataRightsRequest | обработка запросов | при обращении |
| Принятие документов | LegalAcceptance (версия, locale, время) | соблюдение требований | для обязательных документов |
| Аудит / безопасность | AuditLog, SecurityIncident | безопасность, расследования | системные |
| IP / логи | IP в rate limit / серверных логах | безопасность, злоупотребления | **LEGAL REVIEW REQUIRED** (срок хранения) |

5.1. **Геолокация устройства:** координаты GPS могут использоваться **локально на устройстве** для сортировки и карты; **постоянное хранение GPS-профиля пользователя на сервере QalaGo не описано** в текущей архитектуре. В аналитике могут использоваться **обезличенные дистанционные бакеты**, не точные координаты пользователя как постоянный профиль.

8.3. Персональные данные **не продаются** третьим лицам в модели маркетплейса QalaGo; монетизация — подписки и рекламные размещения для бизнеса, а не продажа ПД.

## 9. Сроки хранения

9.1. **Реализованное поведение (техническое):**

- OTP: ~5 минут;
- данные аккаунта: до удаления / частичной анонимизации;
- избранное, отзывы, уведомления пользователя: удаляются при удалении аккаунта (где реализовано);
- заказы/платежи/PlanPayment: **сохраняются** при удалении пользователя — **LEGAL REVIEW REQUIRED**;
- жалобы/модерация: сохраняются для расследований — **LEGAL REVIEW REQUIRED**;
- AnalyticsEvent: **не привязан к userId**; срок хранения **не ограничен** в коде — **LEGAL REVIEW REQUIRED**;
- AuditLog / SecurityIncident: append-only — **LEGAL REVIEW REQUIRED**;
- cookie `qalago_web_session`: до 30 дней (Consumer Web).

9.2. Окончательные сроки для публикации должны быть зафиксированы во [внутренней матрице](../internal/data-retention-deletion-matrix.md) после counsel.

## 10. Права субъекта данных

Применимые права определяются законодательством РК. QalaGo предусматривает:

- **доступ** и **уточнение** — через профиль и/или [PRIVACY_EMAIL];
- **удаление аккаунта** — `DELETE /users/me` (мобильное приложение / API); см. также страницу удаления аккаунта на сайте;
- **запросы субъекта** — `DataRightsRequest` (ACCESS, EXPORT, CORRECTION, DELETE_ACCOUNT и др.) через API; UI на всех клиентах **может быть неполным** — **LEGAL REVIEW REQUIRED**;
- **отзыв согласия** — где обработка основана на согласии; отзыв может ограничить функции — **LEGAL REVIEW REQUIRED** для последствий.

## 11. Безопасность

11.1. Оператор применяет организационные и технические меры: разграничение доступа (RBAC), аутентификация, шифрование каналов (HTTPS в production), журналирование, резервное копирование (по политике хостинга). Детали не раскрываются публично во избежание рисков для безопасности.
